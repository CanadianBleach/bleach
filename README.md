# Bleach

A space-themed developer portfolio built with React Three Fiber featuring an interactive constellation experience.

## Overview

Bleach is a modern 3D portfolio website designed to showcase projects, creativity, and interactive web experiences through immersive visuals and real time rendering. The centerpiece of the portfolio is an interactive constellation system that allows users to explore content in a unique and engaging way.
